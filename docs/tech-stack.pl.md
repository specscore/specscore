# Technologie stojące za SpecScore

Stos technologiczny to zestaw narzędzi używanych do budowy i działania produktu. SpecScore jest otwartym formatem Markdown i YAML dla specyfikacji oprogramowania; ta witryna udostępnia je ludziom i narzędziom.

## Ta witryna

Mały generator w Node.js tworzy dokumentację HTML i stabilną bajtowo kopię Markdown każdej strony. Astro buduje stronę główną i jej tłumaczenia. Pliki statyczne serwuje Cloudflare Workers. Własny generator zachowuje bezpośredni dostęp do surowego Markdown dla agentów i narzędzi wiersza poleceń.

## Produkt

[Format SpecScore](https://github.com/specscore/specscore) przechowuje funkcje, wymagania, plany i kryteria akceptacji jako wersjonowane pliki; specyfikacja i dokumentacja używają licencji [CC BY 4.0](https://github.com/specscore/specscore/blob/main/LICENSE). Osobne [referencyjne CLI](https://github.com/specscore/specscore-cli) sprawdza i przegląda te pliki na licencji [Apache-2.0](https://github.com/specscore/specscore-cli/blob/main/LICENSE).

## Nasze narzędzia tutaj

Używamy CLI SpecScore do sprawdzania drzewa specyfikacji w tym repozytorium. Generator witryny udostępnia te same źródła Markdown jako HTML i surowe pliki, przydatne czytelnikom i agentom.

## Powiązane projekty

[Synchestra](https://synchestra.io/) używa formatu do koordynacji zadań agentów. [DataTug](https://datatug.app/), [MeaningGraph](https://meaninggraph.io/) i [CodeGrapher](https://codegrapher.dev/) to powiązane projekty.
