# As tecnologias do SpecScore

Uma stack tecnológica é o conjunto de ferramentas usado para criar e operar um produto. SpecScore é um formato aberto em Markdown e YAML para especificações de software; este site as apresenta a pessoas e ferramentas.

## Este site

Um pequeno gerador em Node.js publica a documentação em HTML e uma cópia Markdown com bytes estáveis para cada página. Astro constrói a página inicial e suas traduções. Os recursos estáticos são servidos por Cloudflare Workers. O gerador próprio mantém o Markdown original acessível a agentes e ferramentas de linha de comando.

## O produto

O [formato SpecScore](https://github.com/specscore/specscore) guarda funcionalidades, requisitos, planos e critérios de aceitação em arquivos versionados; especificação e documentação usam [CC BY 4.0](https://github.com/specscore/specscore/blob/main/LICENSE). A [CLI de referência](https://github.com/specscore/specscore-cli), separada, verifica e navega nesses arquivos sob [Apache-2.0](https://github.com/specscore/specscore-cli/blob/main/LICENSE).

## Nossas ferramentas aqui

Usamos a CLI SpecScore para verificar a árvore de especificações deste repositório. O gerador do site serve as mesmas fontes Markdown em HTML e como arquivos originais, úteis a leitores e agentes.

## Projetos relacionados

[Synchestra](https://synchestra.io/) usa o formato para coordenar tarefas de agentes. [DataTug](https://datatug.app/), [MeaningGraph](https://meaninggraph.io/) e [CodeGrapher](https://codegrapher.dev/) são projetos relacionados.
