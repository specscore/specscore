# Article locales

One TypeScript module per locale for `/articles/`, `/articles/acceptance-criteria/`, `/articles/ears-requirements/`, `/articles/lint-specs-in-ci/`, `/articles/feature-spec-template/`, `/articles/claude-code-specs/`, and `/articles/spec-management/`. English is the source of the facts. Other locales translate the prose and keep the format samples in English, because the specification's keywords are English. Lint translations are in [`lint/`](lint/). Feature-spec-template translations are in [`template/`](template/). Claude Code and Cursor translations are in [`agents/`](agents/). Spec-management translations are in [`manage/`](manage/).
