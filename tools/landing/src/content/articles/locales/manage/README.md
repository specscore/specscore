# Spec management article copy

One module per locale for `/articles/spec-management/`. The parent locale module imports it and passes it through `ArticleLocale`. English is the source of the facts. Other locales translate the prose. Commands, rule ids, status values, and the workflow excerpt stay in English, because they are the CLI’s text and the format’s keywords.
